# Arboles

## Archivos y carpetas de universidades

Proyecto en Java que representa la estructura de archivos y carpetas de una universidad mediante un árbol.

### Funcionalidades
- Mostrar el árbol de carpetas y archivos.
- Contar los archivos (hojas).
- Calcular la altura del árbol.
- Buscar un archivo por nombre.

### Archivo principal
`Main.java`
